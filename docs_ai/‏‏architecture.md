## Backend Stack
- **Framework**: FastAPI for high-performance asynchronous endpoints.
- **Database**: PostgreSQL is the primary relational database.

## Infrastructure
- **Hosting**: AWS Lambda for serverless scaling of RAG workers.
- **Vector DB**: Pinecone (Production) / SimpleVectorStore (Local testing).
